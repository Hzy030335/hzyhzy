**本地预览**：进入 `resume-site` 目录，执行

```bash
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。直接双击 `index.html` 也可离线查看（网站无任何外部网络依赖）。

## 三、功能与技术实现

### 3.1 基础要求

| 要求 | 实现方式 |
| --- | --- |
| 响应式设计 | 三档断点（980px / 760px / 620px / 420px），移动端顶栏自动折叠为汉堡菜单 |
| 代码结构清晰 | HTML / CSS / JS 三分离，按页面与功能拆分文件，关键代码均有中文注释 |
| 允许使用开源库 | **未使用任何第三方框架或 CDN**：雷达图、图标、灯箱、动画全部手写原生实现 |

### 3.2 页面内容

- **首页** —— 机械风个人照片、姓名与定位、6 个能力标签、4 项数据亮点、三条能力主线、页面快速入口
- **经历页** —— 4 段完整经历（未来太空车 / 非遗调研 / 班级团支书 / 红色志愿），每项附量化数据条；支持按「科创 / 调研 / 志愿 / 学生工作」分类筛选
- **技能页** —— 六维能力雷达图 + 技能进度条 + 工具箱 + 正在补强方向
- **证书页** —— 4 张 **3D 翻转卡片**，正面是证书原件、背面是它的来历与关键数据；背面可放大看高清图，附完整获奖清单
- **联系页** —— 电话 / 邮箱 / GitHub / 网站一键复制、简历二维码、个人档案表、打印存 PDF

### 3.3 创意与交互（加分项）

1. **机械风真人照片处理**
   照片叠加去色 + 冷调着色 + 扫描线纹理 + 循环下移的青色扫描光带 + 四角 HUD 角标 +
   左下角数据铭牌（`ID: HZY-2026 / MAJOR: NUCLEAR ENG`）+ 右上角 `ONLINE` 呼吸指示灯；
   鼠标悬停时恢复彩色并轻微放大。

2. **双主题切换**
   深色「车间夜班」⇄ 浅色「工业蓝图」，配色由 CSS 自定义属性统一管理，选择状态写入 `localStorage` 持久化。

3. **六维技能雷达图（原生 SVG 绘制）**
   由 `pages.js` 动态计算顶点坐标并生成蛛网网格、轴线、数据多边形、数据点与标签，
   进场时以 easeOutCubic 缓动展开；未引入任何图表库，全部为手写数学计算与 DOM 操作。

4. **滚动进场动画**
   基于 `IntersectionObserver`，元素进入视口时渐入上浮；数据卡片数字同步从 0 滚动计数到目标值。

5. **证书 3D 翻转卡片**
   `perspective` + `backface-visibility` + `rotateY` 实现的真 3D 翻转：正面是证书原图与奖项角标，
   背面记录这张证书的来历（赛事/颁发方、我具体做了什么、关键数据）。
   点击卡片或按 `Enter` / `空格` 翻面；背面「查看大图」弹出灯箱，「翻回正面」复位；
   按钮均做了 `stopPropagation`，点按钮不会误触发卡片翻转。

6. **证书灯箱**
   大图弹窗支持点击遮罩关闭、键盘 `←` `→` 切换、`Esc` 关闭，打开时锁定页面滚动。

7. **首页多层滚动视差**
   JS 只把滚动量写进 CSS 变量 `--py` / `--sy`，具体位移交给 CSS 的 `calc()` 乘以不同系数完成——
   背景光晕 0.28、头像 0.06、文字 −0.04、齿轮导轨 −0.15、数据仪表盘 −0.05，速度差形成纵深。
   用 `requestAnimationFrame` 节流，视口外的元素跳过计算；
   系统开启「减少动效」时自动停用，移动端幅度减半。

8. **一键复制联系方式**
   优先调用 `navigator.clipboard`，在非安全上下文（如本地 `file://` 打开）下自动回退到
   `textarea + execCommand` 方案，并弹出吐司提示。

9. **一键打印 / 存 PDF**
   联系页「打印」按钮调用 `window.print()`，配套 `@media print` 样式：自动隐藏导航与按钮、去除深色背景、避免卡片跨页断裂。

10. **无障碍与性能**
   尊重系统 `prefers-reduced-motion` 设置；图标全部为内联 SVG（零额外请求）；证书图使用 `loading="lazy"` 懒加载。

## 四、设计说明

**为什么是「核工重型机械风」**

我学的是核工程与核技术。这套视觉语言对应的是核工业现场给人的感受——
可靠、精密、有力量感，同时带一点警示意味：

- **配色**：炭黑底（`#0b0d10`）+ 工业警示黄（`#ffb020`）+ 反应堆冷却青（`#35d0d8`）
- **形态**：极小红角（2px）、`clip-path` 斜切角、铆钉阵列、等宽字体数据面板
- **纹理**：40px 工程网格底纹、条纹式进度条、机械刻度感卡片
- **动效**：仪表减速感的 easeOutCubic 缓动、扫描光带循环、状态灯呼吸

所有装饰元素均由 CSS 实现，不依赖任何图片素材。

## 五、部署方式

### 更新 GitHub Pages

1. 进入仓库 https://github.com/Hzy030335/hzy1
2. `Add file` → `Upload files`，上传 `resume-site` 目录下的全部文件（注意保持 `assets/` 目录结构）
3. 提交后约 1 分钟生效，访问 https://hzy030335.github.io/hzy1/ 查看

> 提示：仓库中原有的单文件 `index.html` 会被新版本覆盖，原网址保持不变，
> 因此已有的简历二维码无需重新生成。
